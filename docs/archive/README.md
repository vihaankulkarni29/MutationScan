# Archived working documents

These are **historical records of the v2 → v3 rebuild**, kept for provenance.
They describe code that no longer exists.

Nothing here is documentation of the current tool. For that, see the
[README](../../README.md).

| Document | What it was |
|---|---|
| `AUDIT.md` | Line-by-line audit of the v2 codebase that motivated the rebuild |
| `review.md` | Working notes on what to keep, fix or delete |
| `optimal_mutationscan.md` | The design sketch the v3 rebuild was written against |

They mention modules (`analysis/`, `core/`, `biophysics/`, `utils/`), stage
scripts, config schemas and a resistance-interpretation layer that were all
removed in the rebuild. Read them as a record of reasoning, not as a guide to the
code.
